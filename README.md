# Project Risk Assessor

A Python rule-based prototype with two small examples from the masterclass:
construction delivery risk (remaining tasks per worker-day) and a livestock
health flag based on weight loss, feed reduction, and age.

The sample projects and animal records are fictional. These hard-coded
thresholds are teaching examples only—not a substitute for construction
planning, veterinary advice, or a validated risk model.

## Run

Requires Python 3.10 or newer; there are no third-party dependencies.

```powershell
python risk_assessor.py
python -m unittest -v
```
